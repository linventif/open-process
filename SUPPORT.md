# Getting help

Start with the [getting started guide](docs/getting-started.md), the
[README](README.md) and the [documentation index](docs/README.md).
The [data and storage guide](docs/data-and-storage.md) explains saved files and
session restoration.

## Questions, bugs and ideas

Use [GitHub issues](https://github.com/linventif/open-process/issues) for usage
questions, reproducible bugs and feature suggestions. Search existing issues
first. English and French are welcome. For questions, a blank issue is available;
bugs and feature requests have dedicated forms.

Include the release tag or commit, OS, browser and version when relevant, the
notation involved, and what you tried. For a bug, provide reproduction steps,
expected and actual behavior, and a minimal example if possible. For an incorrect
analysis, include the model, input and expected result with an explanation or
reference. Remove confidential information from files, screenshots and logs.

## Private contact

- Vulnerabilities: follow [SECURITY.md](SECURITY.md).
- Harassment or other community concerns: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- Other matters requiring privacy: [contact@open-process.linv.dev](mailto:contact@open-process.linv.dev).

Public issues are preferred for ordinary support so answers can help others.
Support and reviews depend on maintainer availability; there is no guaranteed
response time or dedicated commercial support service.
