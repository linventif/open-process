Prompt initial :

Use case: logo-brand
Asset type: desktop application icon for Open Process, a process modelling and analysis application (BPMN, Petri nets, UML).
Primary request: create one polished application icon continuing the project's existing visual motif: a Petri place circle containing an amber token, a short right-pointing connecting arrow, and an upright rounded P-shaped process element. Together they subtly read O → P.
Style/medium: precise, minimal, flat vector-like graphic with clean antialiased geometry; a finished software icon, not a mockup.
Composition: square 1024x1024 canvas; an ivory rounded-square tile with generous corner radius occupying 94% of the canvas, centered; emblem optically centered inside, balanced generous padding. The O and P should have equal visual weight. Thick navy strokes, broad simple shapes and negative spaces for readability at 32px. The P has a rounded rectangular upper bowl and a straight vertical stem, with a single horizontal compartment line suggesting a diagram task. Circle on the left, short arrow in the middle, P on the right.
Color palette: existing brand deep navy #1B2A41, amber #E39B2E token, warm ivory #F7F7F2 tile.
Scene/backdrop: genuinely transparent outside the rounded-square tile.
Constraints: deliver exactly one standalone icon filling the square canvas. No words, no captions, no letter labels in addition to the P-shaped symbol, no watermark, no perspective, no 3D, no texture, no decorative tiny details, no extra nodes, no gradients, no cast shadow.

Prompt de retouche :

Use case: precise-object-edit. Edit the application icon just generated. Keep the exact O arrow P emblem, navy and amber colors, ivory rounded tile, square framing and placement. Clean up the tile silhouette: make all four sides and all four rounded corners perfectly smooth, precise geometric edges with consistent antialiasing. Remove every stray opaque pixel, fleck, protrusion and ragged mark outside the rounded square. Transparent background must be perfectly clean outside the tile. Make interior colors solid and flat with no mottled texture. Finished production software icon, no text, no additional shapes.
